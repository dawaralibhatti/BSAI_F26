Why use a variable?

1. A name for something unknown
“Is there a number with: doubling it and adding 3 gives its square?” becomes:
Is there an x with 2x + 3 = x²?
Yes: x = 3 (9 = 9) and x = −1 (1 = 1).
2. Talk about every element at once
“Whatever number you pick, if it is greater than 2 then its square is greater than 4” becomes:
For every number n, if n > 2 then n² > 4.

Replacing the vague word “it” by a letter removes any ambiguity.

Three kinds of statements

Universal
True for all elements of a set.
All positive numbers are greater than 0.
Conditional
If one thing is true, then another is too.
If 378 is divisible by 18, then 378 is divisible by 6.
Existential
At least one thing has the property.
There is a prime number that is even.

Universal conditional: many wordings

Formal
For every animal a, if a is a dog, then a is a mammal.
Universal hidden
If a is a dog, then a is a mammal.
Conditional hidden
For every dog a, a is a mammal.
All dogs are mammals.

All of these say the same thing. Being able to translate between them is the skill to practice.

Mixing “for every” and “there is”

Every … has some …
Every real number r has an additive inverse.
For every real r, there is a real s with r + s = 0.
The s depends on r: for r = 5 it is −5.
There is one … for every …
There is a positive integer m such that for every positive integer n, m ≤ n.
One m works for all n: m = 1.

The order matters. In “every, then there is” the thing found can change each time. In “there is, then every” one thing must work for all.

Sets and roster notation

Set
A collection of elements.
x ∈ S: x is in S
x ∉ S: x is not in S
Roster notation
List the elements in braces.
{1, 2, 3}
{1, 2, 3, …, 100}
{1, 2, 3, …} (infinite)
Order and repeats do not matter
{1, 2, 3} = {3, 1, 2} = {1, 1, 2, 3, 3, 3}
Careful
{0} ≠ 0, since {0} is a set with one element. {1, {1}} has 2 elements: the number 1 and the set {1}.

Number sets and builder notation

Named sets
ℝ reals
ℤ integers
ℚ rationals (fractions of integers)
ℝ⁺, ℤ⁺ only positive
0 is neither positive nor negative.
Set-builder
{x ∈ S | P(x)}
“The set of all x in S such that P(x) is true.”
Examples
{x ∈ ℝ | −2 < x < 5}: every real between −2 and 5
{x ∈ ℤ | −2 < x < 5} = {−1, 0, 1, 2, 3, 4}
{x ∈ ℤ⁺ | −2 < x < 5} = {1, 2, 3, 4}

Integers are separate points, so they are discrete. The real line has no gaps, so it is continuous. That is where “discrete mathematics” gets its name.

Subsets

A ⊆ B
Every element of A is also in B.
∀x, if x ∈ A then x ∈ B
A ⊈ B
Some element of A is not in B.
∃x, x ∈ A and x ∉ B
Proper subset
A ⊆ B, and B has at least one element not in A. Every set is a subset of itself, but not a proper one.
∈ is not ⊆
2 ∈ {1, 2, 3} true
{2} ∈ {1, 2, 3} false
{2} ⊆ {1, 2, 3} true
{2} ∈ {{1}, {2}} true

Ordered pairs and tuples

Ordered pair
(a, b): order matters, a is first and b is second.
(a, b) = (c, d) iff a = c and b = d
Examples
(1, 2) ≠ (2, 1)
(3, 1/2) = (√9, 5/10)
(1, 1) is allowed
n-tuple
(x₁, x₂, …, xₙ): same idea with n entries. Two n-tuples are equal when every matching entry is equal.
(1, 2, 3, 4) ≠ (1, 2, 4, 3)

{a, b} = {b, a} but (a, b) ≠ (b, a) unless a = b.

Cartesian products and strings

A × B
All ordered pairs with first entry from A and second from B.
A = {x, y}, B = {1, 2, 3}
A × B = {(x,1), (y,1), (x,2), (y,2), (x,3), (y,3)}
Size and order
|A × B| = |A| · |B|, so 2 · 3 = 6. B × A has the same size but different pairs, so A × B ≠ B × A. ℝ × ℝ is the Cartesian plane.
Strings
An ordered n-tuple written without brackets or commas. A bit string uses only 0 and 1.
{a, b, c} set
(a, b, c) triple
abc string
These are all different objects.

Predicates and domains

Predicate
A sentence with variables that becomes a statement when values are substituted. P(x): "x is even."
Domain D
Values the variable can take: ℤ integers, ℚ rationals, ℝ reals, ℤ⁺.
Truth set
All x in D that make P(x) true.
∀x∈D, P(x): every x works.
∃x∈D such that P(x): at least one works.

In 2x + y = 0, 2 and 0 are constants, x and y are variables, and the whole equation is an expression.

∀ needs every one, ∃ needs just one

Pick a case.

Negate
~∀x P(x) ≡ ∃x ~P(x)
~∃x P(x) ≡ ∀x ~P(x)
~∀x(P→Q) ≡ ∃x(P∧~Q)
"All are" negates to "at least one is not", never "none". Universals use →, existentials use ∧.

Conditionals, negation and scope

Universal conditional
∀x, P(x)→Q(x). False if P true and Q false for some x; vacuously true where P is false. Existentials use ∧: ∃x P(x)∧Q(x).
Negate
All mathematicians wear glasses: some mathematician does not.
Some dogs have wings: no dog has wings.
If x is prime then x is odd: some prime x is not odd (x=2).
Forms
"All squares are rectangles" = ∀x, Square(x)→Rectangle(x). "No dogs have wings" = ∀x, Dog(x)→~Wings(x).
Scope
x in ∀x P(x) is bound; renaming it changes nothing. A free variable makes a predicate, not a statement. "x² ≥ 0" in a theorem means for all x.
Tarski's world
For ∀ find one counterexample, for ∃ one witness. Check the domain first.

Negating ∀ and ∃

Negate “for all”
~(∀x ∈ D, Q(x)) ≡ ∃x ∈ D such that ~Q(x)
“All are” becomes “at least one is not”.
Negate “there exists”
~(∃x ∈ D such that Q(x)) ≡ ∀x ∈ D, ~Q(x)
“Some are” becomes “none are” (all are not).
Examples
All mathematicians wear glasses → there is a mathematician who does not.
Some snowflakes are the same → no two snowflakes are the same.
Caution
“All mathematicians do not wear glasses” is ambiguous. It can mean “none do”, which is stronger than the true negation. Say “some … do not”.

Negations: worked examples

a. ∀ primes p, p is odd.
∃ a prime p such that p is not odd.
(p = 2)
b. ∃ a triangle T whose angles sum to 200°.
∀ triangles T, the angles of T do not sum to 200°.
c. No politicians are honest.
Formal: ∀ politician x, x is not honest.
Negation: ∃ a politician x such that x is honest.
Informally: some politicians are honest.
Method
Rewrite formally, then apply the rule. Or ask: “What exactly would make this false?”

Negating a universal conditional

Rule
~(∀x, P(x) → Q(x)) ≡ ∃x such that P(x) ∧ ~Q(x)
It follows from ~(P → Q) ≡ P ∧ ~Q.
Example 1
∀ person p, if p is blond then p has blue eyes.
Negation: some person is blond and does not have blue eyes.
Example 2
If a program has more than 100,000 lines, then it has a bug.
Negation: some program has more than 100,000 lines and has no bug.

The negation of “if … then” is “… and not …”, never another “if … then”.

∀ is a big AND, ∃ is a big OR

Finite domain D = {x₁, …, xₙ}
∀x ∈ D, Q(x) ≡ Q(x₁) ∧ Q(x₂) ∧ … ∧ Q(xₙ)
∃x ∈ D, Q(x) ≡ Q(x₁) ∨ Q(x₂) ∨ … ∨ Q(xₙ)
Example, D = {0, 1}
∀x, x·x = x ≡ (0·0 = 0) ∧ (1·1 = 1)
∃x, x + x = x ≡ (0 + 0 = 0) ∨ (1 + 1 = 1)
So the negation rules are De Morgan
~(AND) is OR of the negations, and ~(OR) is AND of the negations. That is why ∀ flips to ∃ and ∃ flips to ∀.

Vacuous truth

The bowl
“All the balls in the bowl are blue.” If the bowl is empty, is it true?
Its negation is “some ball in the bowl is not blue”. There is no such ball, so the negation is false and the original is true by default.
Definition
∀x ∈ D, if P(x) then Q(x)
is vacuously true when P(x) is false for every x in D.
Watch out
In maths, “in general” means “always”, not “usually”.

Converse, inverse, contrapositive

Start from: ∀x ∈ ℝ, if x > 2 then x² > 4. This is true.

Contrapositive
∀x, if x² ≤ 4 then x ≤ 2
Always equivalent to the original.
Converse
∀x, if x² > 4 then x > 2
Not equivalent. False: x = −3.
Inverse
∀x, if x ≤ 2 then x² ≤ 4
Not equivalent. False: x = −3.

Necessary, sufficient, only if

PhraseMeans
r(x) is sufficient for s(x)∀x, if r(x) then s(x)
r(x) is necessary for s(x)∀x, if s(x) then r(x)
r(x) only if s(x)∀x, if r(x) then s(x)
Squareness is sufficient for rectangularity: if a figure is a square, then it is a rectangle.
Age 35 is necessary to be president: if x is president, then x is at least 35.
A product is 0 only if a factor is 0: if the product is 0, then one number is 0.

Four words to know

Even
n = 2k
twice some integer
0, 14, −6
Odd
n = 2k + 1
twice an integer, plus 1
7, −301
Prime
n > 1 and the only positive factors are 1 and n.
2, 3, 5, 7, 11, 13
Composite
n > 1 and n = r·s with 1 < r, s < n.
4, 6, 8, 9, 10, 12

Definitions work both ways: if n is even you may write n = 2k, and if n = 2k then n is even. 1 is not prime. Sums, differences and products of integers are integers.

Direct proof in 5 steps

1. Rewrite
“For every x, if P then Q.”
2. Suppose
Take any x with P true. Any x means no special choice.
3. Unpack
Turn words into formulas with the definition (even → 2k).
4. Algebra
Substitute, multiply out, factor.
5. Finish
Name the result as an integer, then use the definition: “so it is even, as was to be shown.”
Watch out
Use a new letter for each unknown: m = 2r and n = 2s. Writing n = 2r forces m = n.

Example: even + even is even

Claim
The sum of any two even integers is even.
Proof
Suppose m and n are any even integers. By definition, m = 2r and n = 2s for some integers r and s.
m + n = 2r + 2s
       = 2(r + s)
Let t = r + s. It is an integer because it is a sum of integers. So m + n = 2t, which is even by definition. ∎

Disprove with a counterexample

The rule
To show “for all x, if P then Q” is false, find one x where P is true and Q is false. One is enough.
Statement
For all real a and b, if a² = b² then a = b.
Counterexample
a = 1, b = −1. Then a² = 1 = b², so P is true. But 1 ≠ −1, so Q is false. The statement is false.
Tip
Stuck proving something? Try negatives, zero and equal values to hunt for a counterexample.

Other ways to prove

Prove ∃ (exists)
Give one example. 10 is even and 10 = 5 + 5 = 3 + 7, two ways as a sum of primes.
Exhaustion
If there are only a few cases, check each one. Every even n from 4 to 26 is a sum of two primes: 4 = 2 + 2, 6 = 3 + 3, 8 = 3 + 5 …
When exhaustion fails
Infinitely many cases, so use a direct proof with a generic x.

Rules for writing a proof

1. Copy the theorem
Write the statement first.
2. Mark “Proof”
Begin with the word Proof.
3. Be self-contained
Introduce every variable and say what kind of object it is: “Suppose m and n are any even integers.”
4. Full sentences
Symbols are fine inside sentences. Read the first = as “equals”, later ones as “which equals”.
5. Show the status
Say what is assumed (“Suppose”) and what is still to be shown (“We must show that”).
6. Give a reason
Every step: by hypothesis, by definition of even, by substitution, by theorem 4.1.1.
7. Little words
Because, Since, Then, Thus, Hence, So. Use Observe that or Recall that for a side fact.
8. Display equations
Put equations on their own lines, with space.

Words that keep a proof clear

Assumed
Suppose … / Assume … / Let x be …
To be shown
We must show that … / In other words, we must show …
Follows from before
Then … by substitution
Hence … by definition of odd
New side fact
Note that … / Observe that … / Recall that …
New variable
Let t = r + s.
New name on the left, its definition on the right. Use “Let”.
Rule of thumb
A reader should never be unsure whether a line is assumed, established, or still to be deduced.

Common mistakes (1 to 4)

1. Arguing from examples
“m = 14 and n = 6, and 14 + 6 = 20 is even” does not prove it for all even m and n. Use an arbitrary m and n.
2. One letter, two meanings
“m = 2k + 1 and n = 2k + 1” forces m = n. Use a new letter: n = 2s + 1.
3. Jumping to a conclusion
After m + n = 2r + 2s, saying “so it is even” is not enough. Show it equals 2(r + s) with r + s an integer.
4. Assuming what is to be proved
“When odd integers are multiplied, their product is odd. Hence mn is odd.” That is the claim itself.

Common mistakes (5 to 7)

5. Known vs still to show
Do not write “there exists s with mn = 2s + 1” as if true. You only know s exists once mn is shown odd. Write “we must show there exists s”. Do not introduce a variable unless it comes from the hypothesis.
6. “any” instead of “some”
“m = 2a + 1 for any integer a” is wrong, since a must equal (m − 1)/2. Write “for some integer a”.
7. “if” instead of “because”
“Suppose p is prime. If p is prime, then …” treats it as doubtful. Write “Because p is prime, …”.

Model proof

Theorem
The difference of any odd integer and any even integer is odd.

Rewrite
For all integers a and b, if a is odd and b is even then a − b is odd.
Proof
Suppose a is any odd integer and b is any even integer. We must show a − b is odd.
By definition, a = 2r + 1 and b = 2s for some integers r and s. Then
a − b = (2r + 1) − 2s substitution
       = 2r − 2s + 1 like terms
       = 2(r − s) + 1 factor 2
Let t = r − s. It is an integer because it is a difference of integers. So a − b = 2t + 1, which is odd by definition. ∎

Spot the mistake, disprove an ∃

Bad proof
Claim: if n is even then (−1)ⁿ = 1.
n = 2a, so (−1)ⁿ = ((−1)ᵃ)²,
= 1 “because a square is positive”.
Mistake: a jump. A square of a nonzero real is positive, but that does not show ((−1)ᵃ)² equals 1.
Disprove an ∃ statement
“There is a positive integer n with n² + 3n + 2 prime.” Prove the negation (a ∀ statement) with a generic n.
n² + 3n + 2 = (n + 1)(n + 2)
Both factors are integers greater than 1, so the number is never prime.
